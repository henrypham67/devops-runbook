# DevOps Runbook

A growing body of DevOps work: hands-on lab write-ups, capstone projects, and
architecture decision records. Every lab leaves an artifact — together they form
a portfolio that doubles as evidence of growth from mid-level toward senior.

## What's here

| Path | What it holds |
| --- | --- |
| [`devops-progress.md`](./devops-progress.md) | The candid skills tracker — current level, strengths, and gaps. Read/updated by the coaching workflow. |
| [`labs/`](./labs/) | One folder per lab write-up. The hands-on artifacts. |
| [`capstones/`](./capstones/) | The larger, multi-part stage projects. |
| [`adr/`](./adr/) | Architecture Decision Records — design decisions made and defended in writing. |

## How to use this repo

- **Labs** capture focused, single-topic exercises. Each gets its own folder
  under `labs/` with a `README.md` documenting the goal, what was built, what
  broke, and what was learned.
- **Capstones** are end-to-end projects that integrate several skills. They live
  under `capstones/`, one folder each.
- **ADRs** record a decision, its context, the options weighed, and the
  consequences. Numbered sequentially (`adr/0001-title.md`). See
  [`adr/0000-template.md`](./adr/0000-template.md).

## Status

🚧 Early days — actively building. The progress file is deliberately candid; this
